Space · Embedded

CubeSat On-Board Computer — CANopen Master

Designed and implemented the OBC firmware acting as CANopen master for internal satellite communication in a 1U CubeSat. This was also the subject of my MSc thesis at UNED. The system coordinates all satellite subsystems, managing power, telemetry and attitude control data over the CAN bus.

C CANopen CubeSat RTOS EnduroSat
Automotive · Python

Automated Testing Framework — Instrument Panel Cluster

Designed and built a comprehensive automated testing framework for automotive dashboard software at Visteon. A single button press triggers full test runs, generates reports, and executes schedules. Dramatically reduced manual QA time and enabled continuous integration for embedded IPC software.

Python Test Automation QNX OS GitLab CI Visteon
Railway · Embedded C

Preventive Maintenance Tool — Paris Metro Trains

Contributed to the development of a new preventive maintenance toolchain for the trains operating in the Paris metro, within Siemens Mobility's tools development department. Embedded C development on VxWorks RTOS, with M2M communication between train subsystems and ground infrastructure.

C / C++ VxWorks M2M Siemens Mobility Akka Technologies
Research · Matlab 🔊

Virtual Instrument — Acoustic Impulse Response Measurement

Designed and developed a complete virtual instrument in Matlab for measuring the impulse response of acoustic systems. This was my BSc thesis at ICAI (Universidad Pontificia Comillas). The tool combined signal processing theory with a practical software interface for acoustic analysis.

Matlab Signal Processing Acoustics ICAI / CSIC
